Sales Dashboard Analysis

Project Overview

This project analyzes sales data using Tableau. The dashboard provides insights into sales performance across months, regions, and product categories.

Dataset

- Source: CSV Sales Dataset
- Tool Used: Tableau

Dashboard Components

1. Line Chart – Sales Over Months
2. Bar Chart – Sales By Region
3. Pie Chart – Sales By Category
4. Region and Category Filters

Key Insights

1. West region recorded the highest sales.
2. Technology category generated the highest sales.
3. Sales reached their peak in November.

Features

- Interactive dashboard
- Region and Category filtering
- Visual comparison of sales trends
- Category-wise sales distribution

Conclusion

The dashboard helps identify top-performing regions and categories while providing a clear view of monthly sales trends. Interactive filters allow users to explore the data efficiently.
